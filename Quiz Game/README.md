# 🎯 Interactive Quiz Game

A responsive, interactive quiz web application built with vanilla HTML5, CSS3, and modern JavaScript.

Created by **Benbrik Adam**.

---

## ✨ Features

- **Dynamic Question Loading**: Questions and multiple-choice answers render dynamically from JavaScript data objects.
- **10-Second Countdown Timer**: Automatic timer per question that skips forward and highlights the correct answer if time runs out.
- **Real-Time Progress & Score Tracking**: Dynamic progress bar updates as you advance through the quiz.
- **Interactive Feedback**: Instant visual cues (green/red) on answer selection.
- **Game Lifecycle Controls**: Includes options to **Restart Quiz** or return to the **Main Menu**.
- **Responsive Design**: Clean UI optimized for desktop and mobile viewports.

---

## 🛠️ Built With

- **HTML5**: Semantic document structure.
- **CSS3**: Flexbox layout, responsive media queries, and transition styling.
- **JavaScript (ES6+)**: DOM manipulation, event listeners, and `setInterval`/`setTimeout` timing logic.
