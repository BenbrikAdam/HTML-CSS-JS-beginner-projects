# 🎨 Color Palette Generator

A clean, responsive color palette generator built with vanilla HTML5, CSS3, and JavaScript. It generates 5 harmonized random HEX colors on demand and allows one-click clipboard copying.

Created by **Benbrik Adam**.

---

## ✨ Features

- **Random Palette Generation**: Generates 5 unique random HEX color codes at the click of a button.
- **One-Click Copy**: Copy any HEX code to your clipboard by clicking either the copy icon or the color tile itself.
- **Visual Copy Feedback**: Instant green checkmark animation confirming that the color code was copied.
- **Responsive Grid**: Fluid layout that reflows automatically on desktop, tablet, and mobile screens.
- **Modern Styling**: Soft gradients, Poppins typography, and smooth hover interactions.

---

## 🛠️ Built With

- **HTML5**: Semantic elements and Font Awesome icon integration.
- **CSS3**: CSS Grid, Flexbox, custom gradients, transitions, and media queries.
- **JavaScript (ES6+)**: DOM manipulation, event delegation, dynamic HEX string generation, and the `navigator.clipboard` API.
